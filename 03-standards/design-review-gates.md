# Design-review gates

A Phase 1 package is not reviewable unless it names:

1. **CM-ID or CORE**
2. **Q01 boundary** — what is in/out of the module
3. **SoR** for each new point (Q05)
4. **Zone** and north/southbound path (Q04)
5. **Failure domain** (which S-IDs) (Q07)
6. **Live-expansion method** (Q08)
7. **Tag dictionary compliance** (Q09)
8. **KPI effect** on PUE/WUE/SLA (Q10)

The ICOA office chairs the review. Power, DC, IT/AI, and ops sign. Missing a row is a **reject**, not a comment.
