# 30 / 60 / 90-day plan

**Purpose of the first three months:** not to finish every engineering detail. **Output:** ICOA v0.9 — how 800 MW Phase 1 becomes the repeatable, secure, interoperable foundation for the 10 GW campus.

Owners: ICOA office (A/R) with the four team leads (Power, DC construction, IT/AI, Operations). Cadence: [../00-program/stakeholders-and-interfaces.md](../00-program/stakeholders-and-interfaces.md).

---

## Days 1–30 — Frame (Q1–Q3)

**Outcome:** One vision, one module, one RACI. No competing “phase 1 specials.”

| # | Work | Done when |
| --- | --- | --- |
| 30.1 | Freeze program envelope in `00-program/` (800 MW / 10 GW, partners, DOE adjacency) | Four leads sign [vision-and-goals](../00-program/vision-and-goals.md) |
| 30.2 | Stand this repo as the only ICOA source of truth | Folder map in root README used in meetings |
| 30.3 | Publish stakeholder RACI and meeting cadence | Named deputies if leads travel |
| 30.4 | **Q01** freeze: 100 MW CM physical + ops + digital boundary | Sketch of CM-01 vs Core on one page |
| 30.5 | **Q02** service catalog: Core vs CM vs support | No second historian “for convenience” |
| 30.6 | **Q03** autonomy matrix v0.1 (A/S/M + AI bounds) | Safety/protection stays A |
| 30.7 | Inventory P1 intended systems (EMS, BMS, CDU, fabric, PAM, twin) **as a list, not a bake-off** | Spreadsheet mapped to SoR columns |
| 30.8 | Data classification sketch (OT-Safety / OT-Ops / IT-Tenant / Public) | Input to day 60 legal addendum |
| 30.9 | Risk list: interconnect, GT, water, DOE, vendor lock | Seed [../06-roadmap/risk-register.md](../06-roadmap/risk-register.md) |

**Day-30 gate:** Architecture forum can explain CM vs Core vs autonomy to an EPC in 20 minutes. If not, do not start vendor down-selects.

---

## What we deliberately do not finish in 90 days

OEM finalists for every skid, GT thermo, 765 kV routing, GPU SKU, production ML models, DOE safety-basis revisions, community legal close. Those run **in parallel** but must **map** to an ICOA question. Unmapped work is how islands start.
