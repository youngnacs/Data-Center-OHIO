# Glossary

Use these words in drawings, tags, contracts, and runbooks. If a vendor uses a different word, map it here — do not let five synonyms into the historian.

| Term | Meaning at PORTS |
| --- | --- |
| **ICOA** | Integrated Campus Operating Architecture — this repository |
| **CM (Compute Module)** | Repeatable **100 MW IT** liquid-cooled AI factory block |
| **Campus Core** | Shared HV, generation interface, water, fiber MMRs, identity, twin, security, Gold IT |
| **Phase 1** | First **800 MW** (8 × CM), construction 2026, energization from 2028 |
| **Full campus** | **10 GW** class energy / ~**8 GW IT** |
| **Gold SLA** | Control plane, core, safety, identity — highest availability, 2N-class |
| **Titanium-Compute SLA** | Training load — block redundant, checkpoint-friendly |
| **SoR** | System of record — the only place a given fact is written |
| **OT** | Operational technology: protection, EMS, BMS, CDUs, fire, physical security |
| **IT** | Enterprise, cluster, tenant, and campus IT including GPU fabric |
| **Purdue / zones** | Segmentation model for OT; PORTS uses zones in Q4, not a flat historian |
| **EPMS** | Electrical power monitoring (meters, PQ, breaker status) |
| **BMS** | Building management (HVAC, liquid, leak, environment) |
| **Twin** | Digital twin — **derived** view, never SoR |
| **Agentic AI** | Software that can propose or (where allowed) take bounded actions |
| **IST** | Integrated systems test / commissioning across trades |
| **Live expansion** | Connecting a new CM while adjacent CMs stay energized |
| **BTM / on-site gen** | Generation dedicated to the campus (gas now; nuclear optional later) |
| **DCT** | AEP Ohio Data Center Tariff |
| **WUE / PUE** | Water / power usage effectiveness; campus KPIs, not vendor slideware |
